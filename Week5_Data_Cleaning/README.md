# Week 5 Assignment - Apache Spark & PySpark

## Overview

This repository contains the solutions for Week 5 of the Celebal Technologies Internship Program. The assignment focuses on Apache Spark concepts and hands-on data processing using PySpark DataFrames.

## Technologies Used

* Apache Spark
* PySpark
* Python
* Jupyter Notebook

## Files Included

* `Week5_Assignment_PySpark.ipynb` - Jupyter Notebook containing all practical implementations and outputs.
* `week5_dataset.csv` - Dataset used for performing Spark DataFrame operations.
* `README.md` - Project documentation.

## Topics Covered

### Theory

* Limitations of MapReduce
* In-Memory Computing in Spark
* DataFrame Immutability
* Handling Null Values
* Shuffle Operations
* Schema Inference Risks

### Practical Tasks

* Removing duplicate records
* Filtering and aggregation
* Handling null values
* GroupBy operations
* Working with timestamps
* Data cleaning
* Aggregate statistics
* Revenue calculation using Spark DataFrames

## Assignment Objectives

The main objective of this assignment is to understand how Apache Spark processes large datasets efficiently and to gain hands-on experience with PySpark DataFrame transformations and actions.

## Learning Outcomes

After completing this assignment, I was able to:

* Load and process datasets using PySpark.
* Perform filtering, aggregation, and transformation operations.
* Handle missing and duplicate data.
* Understand Spark's execution concepts such as shuffling and immutability.
* Build simple data processing pipelines using Spark DataFrames.
