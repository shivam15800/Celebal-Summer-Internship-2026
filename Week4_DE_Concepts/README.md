# Azure Data Factory End-to-End Pipeline

### Objective



Build an end-to-end data pipeline using Azure Storage Account and Azure Data Factory.



### Services Used



&#x20;   Azure Resource Group

&#x20;   Azure Storage Account

&#x20;   Blob Containers

&#x20;   Azure Data Factory

&#x20;   Get Metadata Activity

&#x20;   Copy Data Activity



### Pipeline Flow



CSV File → Blob Storage (Input Container) → Azure Data Factory → Output Container



### Steps Performed



&#x20;   Created Resource Group.

&#x20;   Created Storage Account.

&#x20;   Created Input and Output Containers.

&#x20;   Uploaded CSV file.

&#x20;   Created Azure Data Factory.

&#x20;   Configured Linked Service.

&#x20;   Created Source and Destination Datasets.

&#x20;   Added Get Metadata Activity.

&#x20;   Added Copy Data Activity.

&#x20;   Executed and monitored pipeline.

&#x20;   Verified output file generation.



### Result



The pipeline executed successfully and copied the CSV file from the input container to the output container.
